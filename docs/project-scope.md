# Project Scope Statement

## Project Title
AI-Powered Chatbot Development for Customer Support Automation

## Project Purpose
The purpose of this project is to develop an AI-powered chatbot prototype that can automate common customer support activities and improve service efficiency.

## In-Scope Items
- Customer support chatbot prototype
- FAQ response handling
- Order status enquiry simulation
- Refund and return policy support
- Complaint ticket simulation
- Web-based chatbot interface
- Basic intent-based response handling
- Testing and documentation

## Out-of-Scope Items
- Real payment gateway integration
- Full CRM integration
- Voice assistant
- Mobile application
- Advanced multilingual support

## Major Deliverables
- Project plan document
- Scope statement
- WBS and Gantt chart
- Risk register
- Issue log
- Change request process
- Chatbot prototype
- GitHub and Jira evidence
- Final report and presentation
