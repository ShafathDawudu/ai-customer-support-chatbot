# Change Request Management Process

## Purpose
The purpose of the change request process is to control changes to project scope, schedule, cost, and quality.

## Process Steps

1. A team member or stakeholder submits a change request.
2. The project manager records the request in the change log.
3. The team analyses the impact on time, cost, scope, quality, and risk.
4. The change is approved or rejected.
5. Approved changes are added to Jira as tasks.
6. A GitHub branch is created for technical changes.
7. The change is implemented and tested.
8. The final update is merged into the main branch.
9. Documentation is updated.

## Change Request Form

| Field | Description |
|---|---|
| Change Request ID | Unique ID of the change |
| Requested By | Person requesting the change |
| Date Requested | Date of request |
| Change Description | Explanation of required change |
| Reason for Change | Business or technical reason |
| Impact on Scope | Low / Medium / High |
| Impact on Schedule | Low / Medium / High |
| Impact on Cost | Low / Medium / High |
| Approval Status | Approved / Rejected / Pending |
